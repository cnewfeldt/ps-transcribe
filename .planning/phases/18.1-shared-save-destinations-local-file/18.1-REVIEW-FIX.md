## Fixed Issues

### WR-01 / WR-02: Replace transient `settings.localFileEnabled` toggle with `skipLocalFile` parameter

**Files modified:** `PSTranscribe/Sources/PSTranscribe/Services/SaveDestinations.swift`, `PSTranscribe/Sources/PSTranscribe/App/DictationCoordinator.swift`, `PSTranscribe/Sources/PSTranscribe/Views/ContentView.swift`
**Commit:** 3aa5a04
**Applied fix:** Added `skipLocalFile: Bool = false` parameter to `SaveDestinations.save(...)`, gated the Local File branch on `!skipLocalFile && settings.localFileEnabled`. Removed the toggle pattern at both call sites (`DictationCoordinator.saveDictationToNonLocalDestinations` and `ContentView.stopSession`'s post-save block); each now passes `skipLocalFile: true` explicitly. This subsumes WR-02 (the not-`defer`-protected restore in `ContentView.stopSession`) because the toggle pattern is gone entirely. Existing test calls use the default (`skipLocalFile = false`) and remain unaffected.

### WR-03: Path validation rejects legitimate filenames containing `..` substring

**Files modified:** `PSTranscribe/Sources/PSTranscribe/Services/LocalFileWriter.swift`, `PSTranscribe/Sources/PSTranscribe/Services/ObsidianWriter.swift`
**Commit:** 39743c6
**Applied fix:** Replaced `expanded.contains("..")` substring check with `URL.pathComponents.contains("..")`. Adapted the reviewer's suggestion: the suggested code as written would have failed the existing `traversalRejected` tests, because `URL.standardized` collapses `..` segments (`/tmp/foo/../bar` -> `/tmp/bar`), leaving no `..` in the standardized path's components. Fix checks `pathComponents` BEFORE standardization (using a `preStdURL` local), then standardizes for the return value. Existing traversal tests in both writers pass; legitimate paths like `My..Project` or `notes..2026` are no longer falsely rejected.

### WR-04: `isAnyDestinationEnabled` does not check `localFileRoot.isEmpty`

**Files modified:** `PSTranscribe/Sources/PSTranscribe/Services/SaveDestinations.swift`
**Commit:** bf46470
**Applied fix:** Changed `settings.localFileEnabled` to `(settings.localFileEnabled && !settings.localFileRoot.isEmpty)` in the `isAnyDestinationEnabled` predicate, mirroring the Obsidian/Notion treatment. The default `localFileRoot` is non-empty (`~/Documents/PSTranscribe`), so this only affects the cleared edge case (and existing tests pass without modification).
