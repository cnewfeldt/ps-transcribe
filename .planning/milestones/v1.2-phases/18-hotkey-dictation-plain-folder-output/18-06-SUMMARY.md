## Decisions Made

See frontmatter `key-decisions` for the canonical list. Highlights:

- **`import SwiftUI` added to DictationCoordinator.swift.** Required for `AnyView` in the `attach(windowController:)` closure. Pure additive; no other consumers of SwiftUI in the file.
- **LibraryEntryRow icon swap.** Voice memo now uses `waveform.circle.fill`, dictation now uses `mic.fill` per D-11. The swap maintains visual distinction while honoring the spec.
- **PasteboardTestLock cross-suite mutex.** Swift Testing's `.serialized` trait only orders tests within a single `@Suite` -- multiple suites still run in parallel. NSPasteboard.general is system-global state, so tests in different suites racing on the pasteboard is unavoidable without a cross-suite lock. The actor mutex serializes all clipboard-touching tests across the entire Phase 18 batch. Pattern: `await PasteboardTestLock.shared.acquire()` + `defer { Task { await PasteboardTestLock.shared.release() } }`.
- **DictationCoordinatorStateTests serialized.** Even tests that don't touch the pasteboard fail under heavy parallel load if they rely on Task.sleep deadlines (cancelRevertTask 3s, copiedDismissTask 1s). Cooperative scheduling on overloaded MainActor starves these tasks; serialization gives each test dedicated MainActor time.
- **`entries.first` not `entries.last`.** LibraryStore inserts at index 0, so the most-recent entry is at .first. The plan's spec used .last; this is a documentation bug (the assertions are unchanged in spirit). Switched to .first.
- **Inlined coordinator construction in beginNoOpsWhenSessionAlreadyActive.** The DictationCoordinator holds SessionCoordinator weakly; the makeCoordinator helper's strong reference dies on return, leaving the weak ref nil. The test inlines construction so the SessionCoordinator stays alive for the duration.
- **ISO-8601 date strategy in Codable round-trip test.** LibraryStore persists with `.iso8601`. Default JSONEncoder/JSONDecoder use the `secondsSince1970` strategy which encodes/decodes Double-typed timestamps -- if the test used defaults it would still work for the encode side but the legacy-JSON-with-string-date assertion would fail. Standardized on `.iso8601` everywhere.

## Patterns Established

- **Wave-split coordinator pattern (now complete).** Wave 2 shipped the type + state enum + dependency wiring + internal session-state vars. Wave 4 attaches the begin/end/cancel methods and helpers in the same file, mutating the pre-declared internal state vars without widening visibility further. The clean separation makes each wave reviewable independently.
- **Output-mode branching as conditionals, not delegates.** `endDictation` uses `if mode == .clipboard || mode == .both { ... }` and `if mode == .plainFolder || mode == .both { ... }`. No mode-specific subclasses or delegate dance. Reads top-down.
- **Empty-string sentinel for clipboard-only entries (Open Question §1 RESOLVED).** `LibraryEntry.filePath` stays non-optional; clipboard-only entries get `""`. Matches the existing meeting-flow placeholder pattern (ContentView.swift:905). Combined with `inlineTranscript: String?` (D-12), the user retains their text without changing the field's type.
- **`sourceApp: "PSTranscribe"` literal (Open Question §5 RESOLVED).** Dictation entries record the app that produced them rather than the app the user was paste-targeting. The latter would require accessibility introspection (out of scope per REQUIREMENTS.md).
- **Cross-suite mutex via actor + continuation queue.** PasteboardTestLock pattern composes naturally with Swift Testing's parallel execution. Future Phase 18 tests that touch NSPasteboard can drop the same `acquire`/`release` pair without per-test boilerplate.

**2. [Rule 1 - Bug] LibraryEntryRow icon mapping mismatched D-11 spec**
- **Found during:** Task 1 LibraryEntryRow read.
- **Issue:** Pre-Wave-4 code had `.voiceMemo -> "mic.fill"` and `.dictation -> "mic.circle.fill"`. D-11 says dictation uses `mic.fill`. The plan's grep tests would still pass (because both literals contain `mic.fill` due to the `.` regex any-char), but the visual mapping violated the spec.
- **Fix:** Swapped: `.voiceMemo -> "waveform.circle.fill"` (audio-clip metaphor), `.dictation -> "mic.fill"` (per D-11). Two row types remain visually distinct.
- **Files modified:** `PSTranscribe/Sources/PSTranscribe/Views/LibraryEntryRow.swift`
- **Commit:** `6754a90`

**3. [Rule 1 - Bug] Plan's tests used `entries.last`, but LibraryStore inserts at index 0**
- **Found during:** Task 2 Codable round-trip test failure mid-run.
- **Issue:** The plan's test action spec used `await library.entries.last` to inspect the most-recent entry. `LibraryStore.addEntry` calls `entries.insert(entry, at: 0)`, so the most-recent entry is at index 0, not the end. The test assertion `last?.inlineTranscript == "hello inline"` would either fail (if older entries existed) or accidentally pass (on a clean test fixture).
- **Fix:** Switched all `entries.last` references to `entries.first`. Same semantics; correct index.
- **Files modified:** `DictationCommitFlowTests.swift`, `DictationCancelFlowTests.swift`, `PlainFolderFallbackTests.swift`
- **Commit:** `4960bcf`

**4. [Rule 1 - Bug] `beginNoOpsWhenSessionAlreadyActive` would crash on weak-ref nil**
- **Found during:** Task 2 plan-spec review (before run).
- **Issue:** Plan's test does `let dict = makeCoordinator(); let sessionCoord = dict.sessionCoordinator!`. `makeCoordinator()`'s local `coordinator: SessionCoordinator` goes out of scope on return; `dict.sessionCoordinator` is `weak`, so it becomes nil immediately. Force-unwrap `!` would crash.
- **Fix:** Inlined the construction in this single test so the SessionCoordinator stays alive in the test scope. The other 10 tests in the suite don't read sessionCoordinator after construction, so they're unaffected.
- **Files modified:** `DictationCoordinatorStateTests.swift`
- **Commit:** `4960bcf`

**5. [Rule 1 - Bug] Parallel test execution races NSPasteboard.general across suites**
- **Found during:** Task 2 first run of all 8 suites together.
- **Issue:** Even with `@Suite(.serialized)` on each clipboard-touching suite, multiple SUITES still run in parallel under Swift Testing. `ClipboardRestoreTests.clipboardRestoresAfterDelay` writes "OLD"/"NEW" while `DictationCommitFlowTests.clipboardOnlyModeWritesNoFile` writes "hello world", producing "Expectation failed: ... `nil` == `OLD`" race failures.
- **Fix:** Created `PasteboardTestLock` actor mutex (test-only). Every clipboard-touching test does `await PasteboardTestLock.shared.acquire()` + `defer { Task { await PasteboardTestLock.shared.release() } }` around its NSPasteboard touches. Combined with `.serialized` at suite level, this gives full cross-suite serialization.
- **Files modified:** `PasteboardTestLock.swift` (created), all 5 clipboard-touching test files updated.
- **Commit:** `4960bcf`

**6. [Rule 1 - Bug] DictationCoordinatorStateTests was flaky under parallel load**
- **Found during:** Task 2 run with all suites.
- **Issue:** `cancellingPendingRevertsToListeningAfterTimeout` schedules a Task that awaits 3s then sets state to .listening. The test also waits 3.3s. Under parallel load the cooperative scheduler couldn't deliver the revert task's wakeup before the test's wakeup, leaving state = .cancellingPending and failing the assertion.
- **Fix:** Added `@Suite(.serialized)` to the suite. Each test now gets dedicated MainActor time; the 3s revert task fires before the 3.3s test sleep wakes up.
- **Files modified:** `DictationCoordinatorStateTests.swift`
- **Commit:** `4960bcf`

**7. [Rule 3 - Blocking issue] Codable round-trip test needed ISO-8601 date strategy**
- **Found during:** Task 2 first run.
- **Issue:** The legacy-JSON-with-string-date assertion in `clipboardOnlyEntryPersistsInlineTranscriptViaCodable` uses an ISO-8601 string for `startDate`. Default `JSONDecoder()` uses `.deferredToDate` which expects a Double timestamp -- decode would fail.
- **Fix:** Configured both `JSONEncoder` and `JSONDecoder` with `.iso8601` date strategy. Matches LibraryStore's persistence configuration (`saveToDisk` line 67-68).
- **Files modified:** `DictationCommitFlowTests.swift`
- **Commit:** `4960bcf`
