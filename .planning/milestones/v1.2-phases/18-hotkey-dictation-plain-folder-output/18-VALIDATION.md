## Manual-Only Verifications

| Behavior | Requirement | Why Manual | Test Instructions |
|----------|-------------|------------|-------------------|
| Cmd+Shift+D fires from arbitrary frontmost app (Mail, Safari, Xcode) | DICT-01 / SC #1 | Global hotkey behavior is OS-level; no headless harness | Launch the app, switch focus to Mail/Safari/Xcode, press Cmd+Shift+D, confirm HUD appears within 200 ms by visual smoke test |
| Native macOS HUD vibrancy + bottom-center placement | DICT-04 / D-03 / D-04 | Visual fidelity not testable by snapshot | Trigger a session, verify HUD has translucent vibrancy blur, sits in bottom-quarter of `NSScreen.main`, displays partial transcript + timer + Stop button |
| Pasted text does NOT appear in Alfred / Maccy / Pasta clipboard history | DICT-09 / SC #2 | Requires installing third-party clipboard managers | Install Maccy (free), trigger dictation+commit, paste in target app, then open Maccy — entry must be absent |
| Cancel-confirmation flow at ≥30 s | DICT-08 / SC #4 | UI timing + dual-Esc state machine has UX dependency | Start dictation, wait ≥30 s, press Esc once → HUD subtitle changes; press Esc again within 3 s → HUD dismisses with no commit; repeat with non-press → HUD reverts to listening |
| Press-and-hold short-tap silent cancel | DICT-02 / D-07 | Real key release timing | Switch hotkey mode to `.pressAndHold` in Settings, tap-and-release Cmd+Shift+D in <1 s, confirm no HUD/no commit/no file |
| Pulsing menu bar mic indicator while active | DICT-03 / SC #1 | Animation visual | Start dictation, observe menu bar SF Symbol switches to pulsing mic; stop, confirm reverts to `book.closed` |
| Mutual exclusion notice when meeting active | DICT-11 / SC #5 | Requires meeting recording in flight | Start a meeting recording, press Cmd+Shift+D, confirm HUD shows "Recording in progress — dictation unavailable" and auto-dismisses ~1.5 s later |
| Plain-folder file appears with correct filename + clean markdown | FOLDER-02 / FOLDER-03 / SC #3 | Filesystem inspection | Configure plain folder in Settings, dictate ≥10 short sessions in rapid succession, open Finder on the folder — confirm 10 distinct files with `yyyy-MM-dd HH-mm-ss-SSS Dictation.md` filenames, each starting with `# Dictation -- yyyy-MM-dd HH:mm`, no YAML frontmatter, owner-only 0600 perms |
| Eager pre-warm at app launch (D-13) is silent and complete | D-13 | Background timing not visible | Cold-launch app, immediately press Cmd+Shift+D — first hotkey should not show "Loading model…" state if pre-warm completed; if pre-warm still in flight, HUD shows loading state and resolves to listening |
| 200 ms HUD-appearance budget (SC #1) | DICT-04 / SC #1 | Cannot assert against real `NSPanel` headlessly | Cold and warm runs: trigger Cmd+Shift+D, observe HUD onscreen "instantly"; if instrumenting via `os_signpost`, capture in Instruments and confirm < 200 ms wall-clock from key event to first paint |
