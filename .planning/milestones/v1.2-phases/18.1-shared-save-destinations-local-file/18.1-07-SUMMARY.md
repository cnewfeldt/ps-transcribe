# Phase 18.1 Plan 07: NSOpenPanel Title + Prompt Fix Summary

**One-liner:** Promoted `chooseFolder` helper message string to `panel.title` (high-contrast title bar) and added `panel.prompt = "Choose"` to fix UAT issue #1 -- both folder pickers now show a legible title.

## What Was Built

The `chooseFolder(message:onSelect:)` helper in `SettingsView.swift` previously set only `panel.message`, which renders in a small, low-contrast accessory slot below the title bar. The NSOpenPanel window title bar showed the system default (unset, effectively blank), which UAT reported as "barely legible."

This plan adds two lines to the helper:
- `panel.title = message` -- puts the descriptive string in the high-contrast window title bar slot the user is actually reading
- `panel.prompt = "Choose"` -- replaces the system default "Open" action button label with the in-app verb "Choose"

Both the Local File picker (line 114) and Obsidian picker (line 179) route through this single helper and benefit automatically with no caller changes.

## "Icon not rendering" Sub-Symptom -- Out of Scope

UAT issue #1 contained a secondary report about an icon not rendering on the Choose button. This is out of scope for this plan. The debug session (`18.1-uat-issue-1-choose-folder-ui.md`) established that the Choose-Folder buttons are plain `Button("Choose...")` text -- there is no icon in code. This sub-symptom requires a clarification round-trip with the user before it can be treated as a defect. No SF Symbol was added to the buttons.
