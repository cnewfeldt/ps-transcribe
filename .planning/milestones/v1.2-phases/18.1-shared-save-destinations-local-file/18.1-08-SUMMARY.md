# Phase 18.1 Plan 08: DictationHUD Live Binding (UAT Issue #2) Summary

**One-liner:** Introduced `DictationHUDBinding` SwiftUI wrapper to fix frozen HUD -- coordinator @Observable state now propagates live re-renders instead of snapshot-at-attach.

## What Was Built

### Step A -- TranscriptStore @Observable verification

Confirmed `TranscriptStore` is `@Observable @MainActor` (Sources/PSTranscribe/Stores/TranscriptStore.swift:4,6). This means `coordinator.dictationStore.volatileYouText` reads inside a SwiftUI body ARE tracked by the Observation framework, making the full three-property live binding possible without any additional change.

### Step B -- DictationHUDBinding struct + attach() rewire

Added to the bottom of `DictationCoordinator.swift` (after the file-scope `Notification.Name` extension):

```swift
struct DictationHUDBinding: View {
    let coordinator: DictationCoordinator
    var body: some View {
        DictationHUD(
            state: coordinator.state,
            elapsed: coordinator.elapsed,
            partialText: coordinator.dictationStore.volatileYouText,
            onStop: { [weak coordinator] in
                Task { @MainActor in await coordinator?.endDictation() }
            }
        )
    }
}
```

Updated `attach(windowController:)` from the broken snapshot pattern:

```swift
// BEFORE (frozen -- snapshot at attach time):
windowController.setContent(AnyView(
    DictationHUD(state: state, elapsed: elapsed, partialText: ..., onStop: ...)
))

// AFTER (live -- re-reads on every SwiftUI body evaluation):
windowController.setContent(AnyView(DictationHUDBinding(coordinator: self)))
```

Key details:
- `[weak coordinator]` in the onStop closure preserves the equivalent semantics of the original `[weak self]` (both are weak refs dispatching `endDictation()` on @MainActor)
- `DictationHUD` itself is NOT modified -- `let` properties, 5 #Preview blocks all compile and render identically
- The wrapper is `internal` (not `private`) so `@testable import PSTranscribe` in the test can reference `DictationHUDBinding` directly

### Step C -- Regression test

Created `PSTranscribe/Tests/PSTranscribeTests/Phase18.1/DictationHUDLiveBindingTests.swift` with three test cases:

| Test | Technique | Asserts |
|------|-----------|---------|
| `bodyTracksStateAndElapsed` | Mirror reflection on binding.body | After `_test_setState(.listening)` + `_test_setElapsed(7)`, binding.body reflects updated values |
| `bodyTracksPartialText` | Mirror reflection on binding.body | After `dictationStore.volatileYouText = "the quick brown fox"`, binding.body reflects updated partialText |
| `attachUsesBindingWrapper` | Source-level grep via `String(contentsOf:)` | DictationCoordinator.swift contains `"DictationHUDBinding(coordinator:"` -- prevents silent regression back to snapshot pattern |

The Mirror approach works because `DictationHUDBinding.body` returns a concrete `DictationHUD` value (not an opaque wrapped type), so Mirror's children directly expose the struct's `let` stored properties (`state`, `elapsed`, `partialText`, `onStop`).
