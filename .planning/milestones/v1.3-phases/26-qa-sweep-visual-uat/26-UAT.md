### 4. QA-04 — Security-scoped bookmark survival across relaunch + reboot
expected: speculative original framing — folder URLs persist via `bookmarkData(options: .withSecurityScope)` and survive both app relaunch and macOS reboot.
result: WITHDRAWN
reason: "PS Transcribe is non-sandboxed: `PSTranscribe/Sources/PSTranscribe/PSTranscribe.entitlements` contains only `com.apple.security.device.audio-input` and `com.apple.security.device.screen-capture` — no `com.apple.security.app-sandbox` key. `localFileRoot` and `obsidianFolderPath` persist as plain `String` paths in `UserDefaults` at `AppSettings.swift:81` (var declaration) + `:82` (didSet write) and `AppSettings.swift:96` (var declaration) + `:97` (didSet write), NOT as `bookmarkData(options: .withSecurityScope)`. There is no `startAccessing` / `stopAccessing` / `withSecurityScope` call anywhere in `PSTranscribe/Sources` (verified 2026-05-11 via `grep -r 'withSecurityScope|startAccessing|stopAccessing' PSTranscribe/Sources` — zero matches). The QA-04 premise from `research/PITFALLS.md` line 519 was speculative about a sandboxed scenario that did not materialize; UserDefaults string-path persistence is guaranteed by Apple's UserDefaults contract and survives both relaunch and reboot trivially. The API isn't in use here — there is no bookmark layer to test."
